# 개인정보 처리방침 (TimerUtility)

최종 업데이트: 2026-08-03
버전: 1.3
정본: [일본어판](privacy-policy.md)

언어: [日本語](privacy-policy.md) / [English](privacy-policy.en.md) /
[简体中文](privacy-policy.zh-Hans.md) / [繁體中文](privacy-policy.zh-Hant.md) /
**한국어**

TimerUtility(이하 "앱")는 기능에 필요한 최소한의 데이터만 처리하며 사용자 데이터를
개발자가 운영하는 백엔드로 전송하지 않습니다. 이 방침은 앱, Android 시스템 서비스,
사용자가 선택한 공유 대상에서 이루어지는 처리를 구분하여 설명합니다.

---

## 1. 요약

- 앱에는 개발자가 운영하는 백엔드가 없으며, 개발자는 앱의 사용자 데이터를 자동으로
  수신하거나 원격으로 저장하지 않습니다.
- 타이머, 알람, 세계 시계, 가져온 오디오, 설정 및 진단 로그는 기기에 저장됩니다.
- 광고, 분석 또는 비정상 종료 보고 SDK를 포함하지 않습니다.
- 세계 시계 목록이 비어 있는 상태로 처음 초기화되고 사용자가 시스템 권한 대화상자에서
  허용한 경우에만 대략적인 위치를 Android `Geocoder` 시스템 서비스에 전달합니다.
  이 서비스는 기기 및 서비스 제공자에 따라 네트워크를 사용할 수 있습니다. 앱은 원시 좌표를
  저장하지 않으며 개발자도 이를 받지 않습니다.
- 마이크 입력은 사용자가 활성화한 기기 내 음성 중지 기능에만 일시적으로 사용되며,
  녹음, 저장, 전송 또는 진단 로그 기록을 하지 않습니다.
- 진단 로그는 자동으로 업로드되지 않습니다. 사용자가 Android 공유 시트에서 대상을 선택합니다.

---

## 2. 개발자가 수집하지 않는 데이터

앱은 개발자가 운영하는 서버에 다음 데이터를 수집하지 않습니다.

- 이름, 이메일 주소, 전화번호, 주소 또는 생년월일
- Google, 소셜 미디어 또는 기타 계정 식별자
- IMEI, 광고 ID, ANDROID_ID 또는 기타 기기 식별자
- 연락처, 캘린더, 사진 또는 카메라 데이터
- 음성 녹음 데이터
- 사용 분석, 비정상 종료 보고서 또는 분석 데이터
- 결제 정보(앱 내 구매 기능 없음)

Google Play 데이터 보안에서 수집은 앱 또는 SDK가 데이터를 기기 밖으로 전송하는 처리도
포함합니다. Android `Geocoder` 백엔드의 네트워크 처리 가능성을 고려하여 앱은 대략적인
위치를 '수집함, 공유하지 않음, 선택사항, 앱 기능 목적'으로 신고합니다. 앱과 개발자는 원시
좌표나 원본 지오코딩 응답을 보관하지 않으며, 추론된 시간대 식별자만 기기에 저장합니다.
`Geocoder` API는 시스템 서비스 제공자의 보관
기간과 전송 암호화를 보장하지 않으므로 일시적 처리 또는 전송 중 암호화로 신고하지 않습니다.

## 3. 기기에 저장되는 데이터

| 데이터 | 목적 | 저장 위치 | 삭제 방법 |
| --- | --- | --- | --- |
| 타이머 설정(시간, 라벨, 소리, 다시 알림 등) | 다중 타이머 및 복원 | SQLite (Drift) | 앱 내 UI, 저장공간 삭제 또는 제거 |
| 알람 설정(시간, 반복, 소리 등) | 예약 알람 | SQLite (Drift) | 위와 같음 |
| 프리셋 | 프리셋 기능 | SQLite (Drift) | 위와 같음 |
| 세계 시계(시간대 식별자 및 순서) | 세계 시계 기능 | SQLite (Drift) | 위와 같음 |
| 가져온 오디오 파일, 표시 이름 및 메타데이터 | 미리 듣기 및 알람 재생 | 앱 전용 파일 / SQLite (Drift) | 가져온 소리 관리 UI, 저장공간 삭제 또는 제거 |
| 설정(테마, 언어, 기본 소리, 앱 음량, CVD, 음성 중지, 진단 등) | 설정 유지 | SharedPreferences | 저장공간 삭제 또는 제거 |
| 진단 로그(사용자가 명시적으로 활성화한 경우만) | 문제 해결 | 앱 전용 파일(JSON Lines, 최대 14일 / 총 50 MB / 파일당 1 MB) | 저장공간 삭제 또는 제거 |

가져온 소리는 사용자가 Android 파일 선택기에서 선택하여 앱 전용 저장공간으로 복사한
파일입니다. 앱은 이를 자동으로 외부에 전송하지 않습니다. 마이크 입력과 인식 후보는 저장하지
않으며, 알람 화면이 표시되는 동안에만 사용하고 명령 확인 후 폐기합니다.

## 4. 위치 데이터

- 권한: `ACCESS_COARSE_LOCATION`만 사용하며 `ACCESS_FINE_LOCATION`은 요청하지 않습니다.
- 사용 시점: 비어 있는 세계 시계 목록을 처음 초기화할 때만 사용합니다. 시스템 권한
  대화상자에서 사용자가 허용 또는 거부를 선택합니다.
- 처리: 대략적인 좌표를 Android `Geocoder` 시스템 서비스에 전달하고, 국가 또는 지역
  정보를 `Asia/Tokyo`와 같은 시간대 식별자로 매핑합니다.
- 네트워크: `Geocoder` 백엔드는 기기, OS 및 서비스 제공자에 따라 달라지며 네트워크를
  사용할 수 있습니다. 앱은 제공자의 보관 기간이나 전송 방식을 제어하거나 보장할 수 없습니다.
- 저장: 앱은 원시 좌표나 지오코딩 결과를 Drift, SharedPreferences 또는 진단 로그에
  기록하지 않으며 추론된 시간대 식별자만 저장합니다.
- 권한 거부 시: 기기의 시스템 시간대를 사용합니다.

Android `Geocoder` 공식 문서:
<https://developer.android.com/reference/android/location/Geocoder>

## 5. 권한 사용 목적

앱은 [AndroidManifest.xml](../android/app/src/main/AndroidManifest.xml)에 다음 11개 권한을 선언합니다.

| 권한 | 목적 | 안내 방식 |
| --- | --- | --- |
| `ACCESS_COARSE_LOCATION` | 최초 현재 위치 시간대 추론(4절) | 비어 있는 세계 시계 목록을 처음 초기화할 때의 OS 대화상자 |
| `RECORD_AUDIO` | 알람 중 기기 내 음성 중지 | 음성 중지 활성화 시 OS 대화상자 |
| `POST_NOTIFICATIONS` | 타이머 및 알람 알림 | Android 13+ OS 대화상자 |
| `SCHEDULE_EXACT_ALARM` | 정확한 알람 예약 | 해당 OS 버전의 설정 링크 |
| `USE_EXACT_ALARM` | 시계/알람 용도의 정확한 알람 | 시스템 부여, 대화상자 없음 |
| `USE_FULL_SCREEN_INTENT` | 잠금 화면 위에 알람 화면 표시 | 해당 OS 버전의 설정 링크 |
| `WAKE_LOCK` | 알람 시작 시 CPU 깨우기 | 자동 부여 |
| `VIBRATE` | 알림 및 알람 진동 | 자동 부여 |
| `RECEIVE_BOOT_COMPLETED` | 재부팅 후 예약 복원 | 자동 부여 |
| `FOREGROUND_SERVICE` | 백그라운드 알람 재생 서비스 실행 | 자동 부여 |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 해당 서비스를 미디어 재생 유형으로 선언 | 자동 부여 |

## 6. 진단 로그

사용자가 설정에서 "진단 로그 기록"을 활성화한 경우에만 앱이 기기에 동작 로그를 저장합니다.

- 내용: 타이머/알람 시작, 중지, 다시 알림, 오류 및 권한 결과.
- 제외: 위도/경도, 마이크 입력, 음성 인식 후보 및 사용자가 입력한 라벨.
- 공유: 사용자가 "진단 로그 공유"를 선택한 경우에만 zip 파일을 Android 공유 시트에
  전달합니다. 사용자가 대상을 선택하고 전송을 실행하며 자동 업로드는 없습니다.
- 삭제: 스위치를 끄면 새 기록이 중지됩니다. 기존 파일은 저장공간 삭제 또는 앱 제거로
  완전히 삭제할 수 있습니다.

---

## 7. 제3자 서비스

앱은 제3자 광고, 분석, 비정상 종료 보고 또는 개발자 백엔드 서비스를 사용하지 않습니다.
위치, `Geocoder`, 기기 내 음성 인식 및 알림을 위해 Android 시스템 서비스를 사용하며,
이 처리에는 기기, OS 및 서비스 제공자의 구현과 개인정보 설정도 적용됩니다.

진단 로그를 공유한 경우에는 사용자가 선택한 이메일, 클라우드 저장공간, 메신저 또는 기타
대상의 정책이 적용됩니다. 전체 종속성 목록은
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)를 참조하십시오.

## 8. 아동 개인정보

앱은 13세 미만 아동을 대상으로 하지 않습니다. 아동이 사용하는 경우에도 이 방침과 동일한
처리가 적용되며 개발자는 앱에서 개인 정보를 받지 않습니다.

---

## 9. 보안 및 통신

기기 내 데이터는 Android 앱 전용 저장공간에 저장되고 OS 접근 제어를 따릅니다. 앱에는
개발자가 운영하는 네트워크 엔드포인트가 없습니다. Android 시스템 서비스 또는 사용자가
공유 시트에서 선택한 대상의 전송 방식은 앱에서 제어할 수 없습니다.

---

## 10. 사용자 권리 및 삭제

개발자는 서버에 사용자 데이터를 보유하지 않으므로 개발자가 접근, 수정 또는 삭제할 서버
데이터가 없습니다.

- 가져온 소리: 가져온 소리 관리 UI에서 삭제합니다.
- 타이머와 알람: 해당 앱 내 UI에서 삭제합니다.
- 모든 데이터: Android 설정 > 앱 > TimerUtility > 저장공간 및 캐시 > 저장공간 삭제,
  또는 앱을 제거합니다.

공유 시트를 통해 다른 앱에 이미 전송된 데이터는 해당 대상에서 삭제해야 합니다.
