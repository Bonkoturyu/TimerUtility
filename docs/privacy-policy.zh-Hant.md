# 隱私權政策 (TimerUtility)

最後更新：2026-08-03
版本：1.3
規範原文：[日文版](privacy-policy.md)

語言：[日本語](privacy-policy.md) / [English](privacy-policy.en.md) /
[简体中文](privacy-policy.zh-Hans.md) / **繁體中文** / [한국어](privacy-policy.ko.md)

TimerUtility（以下稱「本應用程式」）僅處理實現功能所需的最少資料，且不會將使用者資料
傳送至開發者營運的後端。本政策分別說明本應用程式、Android 系統服務，以及使用者選擇的
分享目的地所進行的處理。

---

## 1. 摘要

- 本應用程式沒有由開發者營運的後端；開發者不會自動接收或遠端儲存使用者資料。
- 計時器、鬧鐘、世界時鐘、匯入音訊、設定與診斷記錄皆儲存在裝置內。
- 本應用程式未包含廣告、分析或當機回報 SDK。
- 僅在世界時鐘清單為空並首次初始化，且使用者在系統權限對話框允許存取時，本應用程式
  才會將概略位置交給 Android `Geocoder` 系統服務。該服務可能因裝置與服務供應商而
  使用網路。本應用程式不會保存原始座標，開發者也不會收到座標。
- 麥克風輸入僅暫時用於使用者啟用的裝置端語音停止功能，不會錄音、儲存、傳送或寫入診斷記錄。
- 診斷記錄不會自動上傳；使用者透過 Android 分享面板選擇目的地。

---

## 2. 開發者不收集的資料

本應用程式不會在開發者營運的伺服器上收集以下資料：

- 姓名、電子郵件地址、電話號碼、地址或出生日期
- Google、社群媒體或其他帳戶識別碼
- IMEI、廣告 ID、ANDROID_ID 或其他裝置識別碼
- 聯絡人、行事曆、照片或相機資料
- 錄音資料
- 使用情況分析、當機報告或分析資料
- 付款資訊（本應用程式沒有應用程式內購買）

Google Play「資料安全」對「收集」的定義包含應用程式或 SDK 將資料傳送至裝置外的處理。
考量 Android `Geocoder` 後端可能進行網路處理，本應用程式將概略位置申報為「已收集、
不共用、選用、用於應用程式功能」。本應用程式與開發者不會保留原始座標或原始地理編碼
回應，只會在裝置上保存推斷出的時區識別碼。
由於 `Geocoder` API 不保證系統服務供應商的保存期限與傳輸加密，本應用程式不申報暫時
處理或傳輸中加密。

## 3. 儲存在裝置內的資料

| 資料 | 用途 | 儲存位置 | 刪除方式 |
| --- | --- | --- | --- |
| 計時器設定（時間、標籤、音源、稍後提醒等） | 多重計時器與還原 | SQLite (Drift) | 應用程式內介面、清除儲存空間或解除安裝 |
| 鬧鐘設定（時間、重複、音源等） | 排程鬧鐘 | SQLite (Drift) | 同上 |
| 預設 | 預設功能 | SQLite (Drift) | 同上 |
| 世界時鐘（時區識別碼與順序） | 世界時鐘功能 | SQLite (Drift) | 同上 |
| 匯入的音訊檔案、顯示名稱與中繼資料 | 試聽與鬧鐘播放 | 應用程式專用檔案 / SQLite (Drift) | 匯入音源管理介面、清除儲存空間或解除安裝 |
| 設定（主題、語言、預設音源、應用程式音量、CVD、語音停止、診斷等） | 保存設定 | SharedPreferences | 清除儲存空間或解除安裝 |
| 診斷記錄（僅於使用者明確啟用時） | 疑難排解 | 應用程式專用檔案（JSON Lines；最多14天 / 總計50 MB / 每個檔案1 MB） | 清除儲存空間或解除安裝 |

匯入音源是使用者透過 Android 檔案選擇器選取並複製至應用程式專用空間的檔案。
本應用程式不會自動將其傳送至外部。麥克風輸入與辨識候選不會保存，僅在響鈴畫面顯示期間
使用，並在指令比對後捨棄。

## 4. 位置資料

- 權限：僅使用 `ACCESS_COARSE_LOCATION`，不要求 `ACCESS_FINE_LOCATION`。
- 使用時機：僅在空的世界時鐘清單首次初始化時。系統權限對話框由使用者決定允許或拒絕。
- 處理：概略座標會交給 Android `Geocoder` 系統服務，再將國家或地區資訊對應為
  `Asia/Tokyo` 等時區識別碼。
- 網路：`Geocoder` 後端取決於裝置、作業系統與服務供應商，可能使用網路。本應用程式無法
  控制或保證服務供應商的保存期限與傳輸方式。
- 儲存：本應用程式不會將原始座標或地理編碼結果寫入 Drift、SharedPreferences 或
  診斷記錄，只保存推斷出的時區識別碼。
- 拒絕權限時：使用裝置的系統時區。

Android `Geocoder` 官方文件：
<https://developer.android.com/reference/android/location/Geocoder>

## 5. 權限用途

本應用程式在 [AndroidManifest.xml](../android/app/src/main/AndroidManifest.xml) 中宣告以下 11 項權限。

| 權限 | 用途 | 提示方式 |
| --- | --- | --- |
| `ACCESS_COARSE_LOCATION` | 初次依目前位置推斷時區（第4節） | 空的世界時鐘清單首次初始化時的系統對話框 |
| `RECORD_AUDIO` | 響鈴時使用裝置端語音停止 | 啟用語音停止時的系統對話框 |
| `POST_NOTIFICATIONS` | 計時器與鬧鐘通知 | Android 13+ 的系統對話框 |
| `SCHEDULE_EXACT_ALARM` | 安排精確鬧鐘 | 適用版本中的設定入口 |
| `USE_EXACT_ALARM` | 時鐘/鬧鐘用途的精確鬧鐘 | 系統授予，無對話框 |
| `USE_FULL_SCREEN_INTENT` | 在鎖定畫面上顯示響鈴畫面 | 適用版本中的設定入口 |
| `WAKE_LOCK` | 響鈴開始時喚醒 CPU | 自動授予 |
| `VIBRATE` | 通知與鬧鐘震動 | 自動授予 |
| `RECEIVE_BOOT_COMPLETED` | 重新啟動後還原排程 | 自動授予 |
| `FOREGROUND_SERVICE` | 在背景執行鬧鐘播放服務 | 自動授予 |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 將該服務宣告為媒體播放類型 | 自動授予 |

## 6. 診斷記錄

只有使用者在設定中啟用「記錄診斷記錄」後，本應用程式才會在裝置內保存運作記錄。

- 內容：計時器/鬧鐘的開始、停止、稍後提醒、錯誤與權限結果。
- 排除內容：經緯度、麥克風輸入、語音辨識候選與使用者輸入的標籤。
- 分享：僅在使用者選擇「分享診斷記錄」後，zip 檔案才會交給 Android 分享面板。
  使用者選擇目的地並執行傳送；本應用程式不會自動上傳。
- 刪除：關閉開關會停止新增記錄。清除儲存空間或解除安裝可完全刪除現有檔案。

## 7. 第三方服務

本應用程式不使用第三方廣告、分析、當機回報或開發者後端服務。應用程式會使用 Android 的
位置、`Geocoder`、裝置端語音辨識與通知等系統服務；這些處理也受裝置、作業系統、服務
供應商的實作與隱私設定約束。

分享診斷記錄時，使用者所選電子郵件、雲端儲存、通訊應用程式或其他目的地的政策適用。
完整相依項目列表請見 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 8. 兒童隱私

本應用程式並非以 13 歲以下兒童為對象。兒童使用時也適用本政策所述的相同處理方式，
開發者不會從本應用程式收到其個人資訊。

## 9. 安全與通訊

裝置內資料儲存在 Android 應用程式專用空間並受作業系統存取控制。本應用程式不提供
開發者營運的網路端點，也無法控制 Android 系統服務或使用者在分享面板中選擇的目的地
所採用的傳輸方式。

---

## 10. 使用者權利與刪除

開發者未在伺服器上持有使用者資料，因此沒有可由開發者存取、更正或刪除的伺服器資料。

- 匯入音源：在匯入音源管理介面中刪除。
- 計時器與鬧鐘：在對應的應用程式內介面中刪除。
- 全部資料：Android 設定 > 應用程式 > TimerUtility > 儲存空間與快取 >
  清除儲存空間，或解除安裝本應用程式。

已透過分享面板傳送至其他應用程式的資料，必須在該目的地刪除。
