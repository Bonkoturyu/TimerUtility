# プライバシーポリシー (TimerUtility)

最終更新日: 2026-08-03
バージョン: 1.3
原本: 本ファイル (日本語)

言語: **日本語** / [English](privacy-policy.en.md) /
[简体中文](privacy-policy.zh-Hans.md) / [繁體中文](privacy-policy.zh-Hant.md) /
[한국어](privacy-policy.ko.md)

TimerUtility (以下「本アプリ」) は、機能に必要なデータを最小限に扱い、開発者が運用する
バックエンドへユーザーデータを送信しない設計を採用しています。本ポリシーは、本アプリ、
Android のシステムサービス、ユーザーが選択する共有先のそれぞれで行われる処理を説明します。

---

## 1. 要約

- 本アプリに開発者運用のバックエンドはなく、開発者は本アプリからユーザーデータを
  自動的に受信・保存しません。
- タイマー、アラーム、世界時計、取込音源、設定、診断ログは端末内に保存されます。
- 広告 SDK、解析 SDK、クラッシュレポート SDK は同梱していません。
- 世界時計の登録が空の初回初期化時だけ、OS 権限ダイアログで許可された粗い位置情報を Android
  `Geocoder` システムサービスへ渡します。このサービスは環境によってネットワークを
  利用する場合がありますが、本アプリは座標を永続化せず、開発者も受領しません。
- マイク入力は、ユーザーが有効化した音声停止機能の端末内認識にだけ一時利用し、
  録音・保存・送信・診断ログ記録を行いません。
- 診断ログは自動送信しません。共有する場合はユーザーが Share Sheet の宛先を選びます。

---

## 2. 開発者が収集しないデータ

本アプリは開発者運用のサーバーへ次のデータを収集しません。

- 氏名、メールアドレス、電話番号、住所、生年月日
- Google アカウントや SNS アカウントなどの識別子
- IMEI、広告 ID、ANDROID_ID などの端末固有 ID
- 連絡先、カレンダー、写真、カメラのデータ
- 音声の録音データ
- アプリ利用統計、クラッシュレポート、解析データ
- 課金情報 (アプリ内課金は実装していません)

Google Play Data Safety 上の「収集」は、アプリまたは SDK が端末外へ送信する処理を
含む定義です。本アプリは Android `Geocoder` のバックエンド処理を考慮し、概略位置を
「収集あり、共有なし、任意、アプリ機能目的」と申告します。生の座標と
ジオコーディング応答を本アプリや開発者は保持せず、導出したタイムゾーン識別子だけを
端末内へ保存します。ただし、`Geocoder` API は
システムプロバイダー側の保存期間と通信の暗号化を保証しないため、一時処理または
転送中に暗号化済みとは申告しません。

## 3. 端末内に保存するデータ

| データ | 用途 | 保存場所 | 削除方法 |
| --- | --- | --- | --- |
| タイマー設定 (時間、ラベル、音源、スヌーズ等) | 複数タイマー、起動時復元 | SQLite (Drift) | アプリ内 UI、ストレージ消去、またはアンインストール |
| アラーム設定 (時刻、繰り返し、音源等) | 指定時刻アラーム | SQLite (Drift) | 同上 |
| プリセット | プリセット機能 | SQLite (Drift) | 同上 |
| 世界時計 (タイムゾーン識別子、表示順) | 世界時計 | SQLite (Drift) | 同上 |
| 取込音源のファイル、表示名、メタデータ | ユーザー指定音源の試聴と鳴動 | アプリ専有ファイル領域 / SQLite (Drift) | 取込音源管理 UI、ストレージ消去、またはアンインストール |
| ユーザー設定 (テーマ、言語、デフォルト音源、アプリ音量、CVD、音声停止、診断ログ等) | 設定の永続化 | SharedPreferences | ストレージ消去、またはアンインストール |
| 診断ログ (明示的に有効化した場合のみ) | 不具合解析補助 | アプリ専有領域 (JSON Lines、最大14日 / 合計50 MB / 1ファイル1 MB) | ストレージ消去、またはアンインストール |

取込音源はユーザーが Android のファイル選択画面で選んだファイルをアプリ専有領域へ
コピーします。本アプリが自動的に外部へ送信することはありません。

マイク入力と認識候補は保存対象ではありません。鳴動画面が表示されている間だけ端末内
認識へ渡し、停止コマンドの判定後に破棄します。

## 4. 位置情報の取扱い

- 権限: `ACCESS_COARSE_LOCATION` のみ。`ACCESS_FINE_LOCATION` は要求しません。
- 利用時: 世界時計の登録が空の初回初期化時だけです。OS 権限ダイアログで許可を確認します。
- 処理: 粗い座標を Android `Geocoder` システムサービスへ渡し、国・地域情報から
  タイムゾーン識別子 (例: `Asia/Tokyo`) を推定します。
- ネットワーク: `Geocoder` のバックエンド実装は端末・OS・サービスプロバイダーに
  依存し、ネットワークを利用する場合があります。本アプリはプロバイダー側の保存期間や
  通信方式を制御・保証できません。
- 保存: 本アプリは生の緯度経度とジオコーディング結果を Drift / SharedPreferences /
  診断ログへ保存せず、推定したタイムゾーン識別子だけを保存します。
- 拒否時: 端末のシステムタイムゾーンへフォールバックします。

Android `Geocoder` の公式仕様:
<https://developer.android.com/reference/android/location/Geocoder>

## 5. 権限の利用根拠

本アプリが [AndroidManifest.xml](../android/app/src/main/AndroidManifest.xml) で宣言する
11 権限の用途は次のとおりです。

| 権限 | 利用目的 | 通知タイミング |
| --- | --- | --- |
| `ACCESS_COARSE_LOCATION` | 世界時計の初期登録で現在地タイムゾーンを推定 (§4) | 登録が空の初回初期化時の OS ダイアログ |
| `RECORD_AUDIO` | 端末内音声認識による鳴動停止 | 音声停止を有効化した時の OS ダイアログ |
| `POST_NOTIFICATIONS` | タイマー / アラーム通知 | Android 13+ の OS ダイアログ |
| `SCHEDULE_EXACT_ALARM` | Exact Alarm の予約 | 対象 OS では設定画面へ誘導 |
| `USE_EXACT_ALARM` | 時計 / アラーム用途の Exact Alarm | システム付与、ダイアログなし |
| `USE_FULL_SCREEN_INTENT` | ロック画面上の鳴動画面 | 対象 OS では設定画面へ誘導 |
| `WAKE_LOCK` | 鳴動時に CPU を起床状態へ移行 | 自動付与 |
| `VIBRATE` | 通知 / アラームの振動 | 自動付与 |
| `RECEIVE_BOOT_COMPLETED` | 再起動後の予約復元 | 自動付与 |
| `FOREGROUND_SERVICE` | バックグラウンドのアラーム再生 Service | 自動付与 |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 上記 Service の media playback 種別 | 自動付与 |

## 6. 診断ログ

設定の「診断ログを記録」をユーザーがオンにした場合だけ、内部動作ログを端末内へ保存します。

- 内容: タイマー / アラームの開始・停止・スヌーズ、エラー、権限結果など。
- 除外: 緯度経度、マイク入力、音声認識候補、ユーザー入力ラベルは記録しません。
- 共有: 「診断ログを共有」を押した場合だけ zip を Android Share Sheet へ渡します。
  宛先と送信操作はユーザーが選択し、本アプリは自動アップロードしません。
- 削除: トグルをオフにすると新規記録を停止します。既存ログの完全削除はストレージ消去
  またはアンインストールで行います。

## 7. 第三者サービス

本アプリは第三者の広告、解析、クラッシュレポート、開発者バックエンドを利用しません。
一方、機能の実行時には Android の位置情報、`Geocoder`、端末内音声認識、通知などの
システムサービスを利用します。これらの処理は端末・OS・サービスプロバイダーの
プライバシー設定と実装にも従います。

診断ログを共有した場合は、ユーザーが選んだメール、クラウドストレージ、メッセージアプリ等の
規約とポリシーが適用されます。完全な依存リストは
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) を参照してください。

## 8. 子どものプライバシー

本アプリは 13 歳未満の子どもを対象として設計されていません。子どもが利用した場合も
本ポリシーと同じ処理が適用され、開発者が本アプリから個人情報を受領することはありません。

---

## 9. セキュリティと通信

端末内データは Android のアプリ専有領域に保存され、OS のアクセス制御に従います。
本アプリは開発者向けの通信エンドポイントを運用していません。Android のシステムサービスや、
ユーザーが Share Sheet で選んだ宛先の通信方式は、本アプリでは管理できません。

---

## 10. ユーザーの権利と削除

開発者がサーバー上に保持するユーザーデータはないため、開発者側で開示・訂正・削除する
サーバーデータはありません。端末内データは次の方法で削除できます。

- 取込音源: アプリ内の取込音源管理 UI から削除
- タイマー / アラーム等: 対応するアプリ内 UI から削除
- 全データ: Android 設定 → アプリ → TimerUtility → ストレージとキャッシュ →
  ストレージを消去、またはアプリをアンインストール

Share Sheet で外部アプリへ共有済みのデータは、その宛先側で削除してください。
