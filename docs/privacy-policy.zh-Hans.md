# 隐私政策 (TimerUtility)

最后更新：2026-08-03
版本：1.3
规范原文：[日文版](privacy-policy.md)

语言：[日本語](privacy-policy.md) / [English](privacy-policy.en.md) /
**简体中文** / [繁體中文](privacy-policy.zh-Hant.md) / [한국어](privacy-policy.ko.md)

TimerUtility（以下简称“本应用”）仅处理实现功能所需的最少数据，并且不会将用户数据发送到
开发者运营的后端。本政策分别说明本应用、Android 系统服务以及用户选择的分享目标所进行的处理。

---

## 1. 概要

- 本应用没有由开发者运营的后端；开发者不会自动接收或远程保存本应用的用户数据。
- 计时器、闹钟、世界时钟、导入音频、设置和诊断日志保存在设备内。
- 本应用不包含广告、分析或崩溃报告 SDK。
- 仅当世界时钟列表为空并首次初始化，且用户在系统权限对话框中允许访问时，本应用才会把
  粗略位置传给 Android `Geocoder` 系统服务。该服务可能因设备和服务提供商而使用网络。
  本应用不保存原始坐标，开发者也不会收到坐标。
- 麦克风输入仅临时用于用户启用的设备端语音停止功能，不会被录音、保存、发送或写入诊断日志。
- 诊断日志不会自动上传；用户通过 Android 分享面板选择目标。

---

## 2. 开发者不收集的数据

本应用不会在开发者运营的服务器上收集以下数据：

- 姓名、电子邮件地址、电话号码、住址或出生日期
- Google、社交媒体或其他账户标识符
- IMEI、广告 ID、ANDROID_ID 或其他设备标识符
- 通讯录、日历、照片或相机数据
- 录音数据
- 使用情况分析、崩溃报告或分析数据
- 付款信息（本应用没有应用内购买）

Google Play“数据安全”对“收集”的定义包括应用或 SDK 将数据传输到设备外的处理。
考虑到 Android `Geocoder` 后端可能进行网络处理，本应用将粗略位置申报为“已收集、
不共享、可选、用于应用功能”。本应用和开发者不会保留原始坐标或原始地理编码响应，
只会在设备上保存推断出的时区标识符。
由于 `Geocoder` API 不保证系统服务提供商的保存期限和传输加密，本应用不申报临时处理或
传输中加密。

## 3. 保存在设备内的数据

| 数据 | 用途 | 保存位置 | 删除方式 |
| --- | --- | --- | --- |
| 计时器设置（时长、标签、音源、稍后提醒等） | 多计时器和恢复 | SQLite (Drift) | 应用内界面、清除存储空间或卸载 |
| 闹钟设置（时间、重复、音源等） | 定时闹钟 | SQLite (Drift) | 同上 |
| 预设 | 预设功能 | SQLite (Drift) | 同上 |
| 世界时钟（时区标识符和顺序） | 世界时钟功能 | SQLite (Drift) | 同上 |
| 导入的音频文件、显示名称和元数据 | 试听和闹钟播放 | 应用专用文件 / SQLite (Drift) | 导入音源管理界面、清除存储空间或卸载 |
| 设置（主题、语言、默认音源、应用音量、CVD、语音停止、诊断等） | 保存设置 | SharedPreferences | 清除存储空间或卸载 |
| 诊断日志（仅在用户明确启用时） | 故障排查 | 应用专用文件（JSON Lines；最多14天 / 总计50 MB / 每个文件1 MB） | 清除存储空间或卸载 |

导入音源是用户通过 Android 文件选择器选择并复制到应用专用存储空间的文件。本应用不会自动
将其发送到外部。麦克风输入和识别候选不会保存，仅在响铃界面显示期间使用，并在命令匹配后丢弃。

## 4. 位置信息

- 权限：仅使用 `ACCESS_COARSE_LOCATION`，不请求 `ACCESS_FINE_LOCATION`。
- 使用时机：仅当空的世界时钟列表首次初始化时。系统权限对话框由用户决定允许或拒绝。
- 处理：粗略坐标传给 Android `Geocoder` 系统服务，再把国家或地区信息映射为
  `Asia/Tokyo` 等时区标识符。
- 网络：`Geocoder` 后端取决于设备、操作系统和服务提供商，可能使用网络。本应用无法控制或
  保证服务提供商的保存期限和传输方式。
- 保存：本应用不会把原始坐标或地理编码结果写入 Drift、SharedPreferences 或诊断日志，
  只保存推断出的时区标识符。
- 拒绝权限时：使用设备的系统时区。

Android `Geocoder` 官方文档：
<https://developer.android.com/reference/android/location/Geocoder>

## 5. 权限用途

本应用在 [AndroidManifest.xml](../android/app/src/main/AndroidManifest.xml) 中声明以下 11 项权限。

| 权限 | 用途 | 提示方式 |
| --- | --- | --- |
| `ACCESS_COARSE_LOCATION` | 初次根据当前位置推断时区（第4节） | 空的世界时钟列表首次初始化时的系统对话框 |
| `RECORD_AUDIO` | 响铃时使用设备端语音停止 | 启用语音停止时的系统对话框 |
| `POST_NOTIFICATIONS` | 计时器和闹钟通知 | Android 13+ 的系统对话框 |
| `SCHEDULE_EXACT_ALARM` | 安排精确闹钟 | 适用版本中的设置入口 |
| `USE_EXACT_ALARM` | 时钟/闹钟用途的精确闹钟 | 系统授予，无对话框 |
| `USE_FULL_SCREEN_INTENT` | 在锁屏上显示响铃界面 | 适用版本中的设置入口 |
| `WAKE_LOCK` | 响铃开始时唤醒 CPU | 自动授予 |
| `VIBRATE` | 通知和闹钟振动 | 自动授予 |
| `RECEIVE_BOOT_COMPLETED` | 重启后恢复预约 | 自动授予 |
| `FOREGROUND_SERVICE` | 在后台运行闹钟播放服务 | 自动授予 |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 将该服务声明为媒体播放类型 | 自动授予 |

## 6. 诊断日志

只有用户在设置中启用“记录诊断日志”后，本应用才会在设备内保存运行日志。

- 内容：计时器/闹钟的开始、停止、稍后提醒、错误和权限结果。
- 排除内容：经纬度、麦克风输入、语音识别候选以及用户输入的标签。
- 分享：仅在用户选择“分享诊断日志”后，zip 文件才会交给 Android 分享面板。
  用户选择目标并执行发送；本应用不会自动上传。
- 删除：关闭开关会停止新增记录。清除存储空间或卸载可完全删除现有文件。

## 7. 第三方服务

本应用不使用第三方广告、分析、崩溃报告或开发者后端服务。应用会使用 Android 的位置、
`Geocoder`、设备端语音识别和通知等系统服务；这些处理也受设备、操作系统、服务提供商的
实现和隐私设置约束。

分享诊断日志时，用户所选电子邮件、云存储、通信应用或其他目标的政策适用。依赖项完整列表见
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 8. 儿童隐私

本应用不面向 13 岁以下儿童。儿童使用时也适用本政策所述的相同处理方式，开发者不会从
本应用接收其个人信息。

---

## 9. 安全与通信

设备内数据保存在 Android 应用专用存储空间并受操作系统访问控制。本应用不提供开发者运营的
网络端点，也无法控制 Android 系统服务或用户在分享面板中选择的目标所采用的传输方式。

---

## 10. 用户权利与删除

开发者没有在服务器上持有用户数据，因此没有可由开发者访问、更正或删除的服务器端数据。

- 导入音源：在导入音源管理界面中删除。
- 计时器和闹钟：在对应的应用内界面中删除。
- 全部数据：Android 设置 > 应用 > TimerUtility > 存储和缓存 > 清除存储空间，或卸载本应用。

已经通过分享面板发送到其他应用的数据，需要在目标应用中删除。
